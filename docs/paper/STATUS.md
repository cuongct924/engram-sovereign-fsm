# Paper status

Reference for building `main.tex`, where each number lives, and which claims still lack
evidence. `docs/EXPERIMENT.md` is the record of which measurements are live, in-process, or
synthetic.

## Build

```bash
make paper    # latexmk out of tree into build/paper/, outputs docs/paper_$(PAPER_VERSION).pdf (default v0; raise it on every rebuild after a source change: make paper PAPER_VERSION=v1)
make paper-split    # same PAPER_VERSION; also writes docs/paper_main.pdf (body + references) and docs/paper_supplement.pdf (appendices)
```

## Porting to a journal template

1. Download the journal's template and put its class file next to `main.tex` (or use the class the journal provides on Overleaf).
2. Copy `main.tex` to `main_<journal>.tex`. Replace the `\documentclass` line, the `\input{template/article}` line and the title block and abstract with the template's.
3. Keep `\input{preamble}`, `\input{content/body}` and `\input{content/appendix}`. If the class clashes with a package of `preamble.tex` (for example `cite`, `hyperref` or `geometry`), remove that package from your copy of the preamble, not from the content.
4. Set the bibliography style with the template's own `\bibliographystyle` in place of `\paperbibstyle`.
5. Build, then check the wide tables (`table*` in a two-column class), the taxonomy figure in `sections/02_related_work.tex` and the appendix tables, which are the parts that depend on the column width.
6. The sections and appendices are not edited for a template, so every journal shares one text.

## Resolving a pending result

`make paper-pending` lists every `\pending{...}` with its file and line. A result is placed in three steps: regenerate the table or figure with its script (the output goes to `results/` or `figures/`, and `\input` or `\includegraphics` already points there), replace the numbers in the text that the table does not carry, and delete the `\pending{...}` that waited for it. A build with `\draftfalse` stops at the first pending left, so none can reach a submission.

This directory holds only the sources that compile the paper (`.tex`, `.bib`, figures) and this note, so it can be uploaded to Overleaf as it is. Build products go to `build/paper/` and the helper that splits the PDF is `scripts/paper/split_pdf.sh`.

| Switch (`macros.tex`) | Default | Effect |
|---|---|---|
| `\drafttrue` / `\draftfalse` | draft | Draft renders `\pending{...}` in red. A final build stops at the first unresolved `\pending`. |
| `\testbedBtrue` / `\testbedBfalse` | false | Adds the Testbed B text; the Testbed B column and results are absent until those experiments exist. |

Names are ASCII because the installed TeX Live has no Vietnamese (T5) encoding.
