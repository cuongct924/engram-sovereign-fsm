\section{Formal Verification Details}
\label{app:formal}

This appendix holds the configurations and the negative or incomplete results that Section~\ref{sec:formal} summarizes.

\subsection*{Refinement obligation C1}

\textbf{Splitting.} To make C1 tractable we split it by which actions may
fire and check each part with TLC under symmetry reduction over the three honest
validators. With the consensus core frozen, the environment part (sensor updates,
clock ticks, DA backfill) completed: 17{,}500 distinct states, depth 10,
10\,m\,35\,s, no violation. With the environment frozen, the consensus-core part
did not complete: it was stopped after 1\,h\,41\,m at 19{,}848{,}141 distinct
states (depth 15, 13{,}542{,}792 states still queued) with no violation. Neither
part covers the interleaving of environment and consensus steps, and no
composition argument is established, so C1 is not claimed.

\textbf{Existence check.} We also looked for a configuration in which each part
completes. A configuration is usable only if a round change, a proposal by a
Byzantine validator and a decided block are all reachable in it, since a completed
run without them would be vacuous. At $N{=}4$, $f{=}1$ with smaller timestamp and
height bounds, a round change and a Byzantine proposal were reached in seconds,
but a decided block was not: not in the consensus-core part at three
configurations (stopped after 25 to 67 minutes at 7 to 30 million states), and not
at the smallest rung of a monolithic ladder over the whole server layer (one
round, one height, three timestamps; stopped after 2\,h\,5\,min at about 13
million distinct states). None of these configurations is reported as a result.

\textbf{Target and mapping.} The server layer carries two guards that
stop it from certifying a timeout for a round an honest validator has already
left, and one added abstract action for a round ended by a quorum of nil
precommits. These are changes to the checked model, and the last weakens the
target specification, so the target is an extension of the object of
LiDO~\cite{qiu2024lido}, not that object. The mapping from the server layer to it
also simplifies four things: \textsc{Suspicious} is mapped to \textsc{Anchored}; a
single fixed quorum, with local time, is distinguished in the abstract object;
every validator has the same voting power; and the Bitcoin height is translated
by $K_{\text{DEEP\_FINALITY}}$. The obligation is a safety obligation only;
refinement of the liveness properties is outside it. These choices bear on what a
completed run of C1 would establish, so we state them here.

\textbf{Tool limit.} An inductive check of every server action would avoid the
composition gap. We tried it with Apalache, which could not represent the
refinement mapping (it does not implement a set filter over a powerset), so the
refinement rests on TLC alone.
